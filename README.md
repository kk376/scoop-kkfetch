# scoop-kkfetch

Scoop bucket for KKFetch.

## Installation

Add this bucket to Scoop:

```powershell
scoop bucket add kkfetch https://github.com/kk376/scoop-kkfetch
scoop install kkfetch
```

Or install directly from the manifest URL:

```powershell
scoop install https://raw.githubusercontent.com/kk376/scoop-kkfetch/main/bucket/kkfetch.json
```

## Update

To update KKFetch to the latest version:

```powershell
scoop update kkfetch
```

## Packages

- **kkfetch**: Fast, lightweight Linux and Windows system information fetch tool written in Rust by Kushagra Kumar (kk376).
